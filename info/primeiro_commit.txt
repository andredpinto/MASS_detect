Quando fizerem o vosso primeiro commit, pode aparecer uma mensagem do género:
"Author identity unknown ..."

Sigam os comandos que são recomendados para o git do vosso pc "assinar" os vossos commits com o vosso email e nome, desta forma o gitlab também associa as vossas contas no site.

$ git config user.email "up...@edu.fc.up.pt"  --  Email
$ git config user.name "Nome_do_gitlab"  --  Nome

Reparem que não coloquei o --global que aparece na mensagem. Isto é só para não associarem este email a todos os futuros commits que fizerem em outros projetos porque (como é o meu caso) na conta do github podem ter um email e um nome diferentes. Ao não porem o --global, o nome e o email ficam associados apenas a este repositório (o que significa que quando trabalharem num repositório diferente vão ter de repetir isto).

Extra:
Se quiserem saber mais sobre como isto funciona, tem a ver com os ficheiros de configuração do git. Quando usam o --global, o nome/email que inserirem fica guardado no ficheiro de configuração global do git (não sei qual é, mas deve existir). Sem o --global, a infomação fica guardada algures dentro da pasta .git que aparece no repositório (no vosso pc, no gitlab não), daí a configuração servir apenas para este repositório específico.
